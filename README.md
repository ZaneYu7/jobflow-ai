# JobFlow AI

A full-stack job application and interview management platform built as a production-oriented portfolio project.

## Project Status

Milestone 0 — Project initialization and development environment setup.

## Planned Technology Stack

- Frontend: React, TypeScript, Vite and Tailwind CSS
- Backend: Java 21, Spring Boot and Maven
- Database: PostgreSQL and Flyway
- Testing: JUnit 5, Testcontainers, Vitest, React Testing Library and Playwright

## Architecture

The application will begin as a modular monolith with a React single-page application and a Spring Boot REST API.

Detailed setup and architecture documentation will be added as the project evolves.
